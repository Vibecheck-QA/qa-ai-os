# Validate gate (stub)

**When:** before building past a prototype.

## Business questions
- What demand signal did you set IN ADVANCE, with a pass mark and a kill mark? (If the repo uses Main Branch, this is a bet in bets/ with a kill_rubric.)
- Did real people act (reply, pay, sign up), not just say they liked it?

## Technical questions
- Did a throwaway prototype prove the riskiest unknown from the Idea gate?
- What did the prototype get wrong that the real build must not repeat?

## Verdict
PASS / HOLD / KILL with evidence for each question. Stub: questions only — evidence rules come in a later version.
